This was the first PCB project I have done in Altium, and the first project other than the connection PCBs I have done. Therefore, the main purpose was to learn the basics, get used to Altium Designer, and make the first step into professional PCB design. Moreover, since it was a learning experience, this design has several issues that need to be optimized. However, since my purpose was learning the basics, I kept this issues in my mind and limited my design to single layer to keep it simple, and focus on learning Altium.

Optimizations and plans for future design,

1. Single-Layer design comes with non-optimized area usage, making a 2 or several layer design will make the PCB smaller and compact, while reducing noise with a dedicated ground plane.
2. DRC rules need to be inspected and corrected, I used Altium's default DRC rules besides the ones that I changes ( I changed wire thickness and minimum annular ring)
